# DevQuery — Community-Driven Q&A Platform

## Link : https://dev-overflow-git-homepageoriginal-sasank-prajapatis-projects.vercel.app/

A **full-stack Q&A platform for programmers** built with **Next.js (App Router), TypeScript, MongoDB, and Server Actions**.  
The platform enables global knowledge sharing, collaboration, and community-driven discussions — inspired by Stack Overflow but built from scratch.

---

## ✨ Features
- **Community Q&A**  
  Post, view, and answer programming questions.  

- **Voting System**  
  Upvote/downvote answers to highlight the best solutions.  

- **Search & Filtering**  
  - Global search across all questions  
  - Localized search within tags  
  - Advanced filtering for most relevant results  

- **User Engagement Tools**  
  - Save/bookmark questions  
  - Manage personal profile  
  - Follow tags for personalized feeds  

- **Tag-Based Filtering**  
  Organize and explore questions efficiently by technology/topic tags.  

- **Performance Optimized**  
  - Lighthouse scores: **70+ Performance & Accessibility**, **80 SEO**  
  - Server Actions for fast, optimized data fetching  

---

## 🛠 Tech Stack
- **Frontend**: [Next.js 14+](https://nextjs.org/) (App Router) with **TypeScript**  
- **Backend**: Next.js Server Actions  
- **Database**: MongoDB  
- **Styling**: Tailwind CSS  
- **Auth**: NextAuth.js (if implemented)  
- **Deployment**: Vercel
